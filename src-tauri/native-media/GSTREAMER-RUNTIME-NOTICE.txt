Affect Research private GStreamer runtime

This internal, pre-release runtime is derived from the official GStreamer
1.28.6 MSVC x86_64 installer. It is dynamically linked and is not a claim that
every container, codec, profile, pixel format, or damaged file is supported.
Only the separately published and physically tested qualification matrix may
be treated as supported for an experiment.
