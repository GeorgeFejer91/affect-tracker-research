About & CLI library

Design an experiment in Experiment Planner. Use its JSON recipe in the separate Experiment Runner for participant sessions.

Planner owns questionnaires, video sequences, layout and feedback settings. Runner owns execution, participant responses, actual timing and recording. A saved recipe describes an experiment; it does not establish qualified playback or recording.

Calling the CLI

Start the local executable with its supported ingress:

affect-planner-cli jsonl

Wait for the ready receipt. Each invocation has a new sessionId. Send one JSON object per line, with a new caller-generated UUID as requestId. Queries use expectedRevision: null; edits use the latest returned revision.

Request envelope

Replace both placeholders with actual UUIDs and send the resulting object on one line. This is a template, not a ready-to-send request.

{
  "schema": "affect-research-planner-command",
  "version": 1,
  "sessionId": "<UUID from the ready receipt>",
  "requestId": "<new caller UUID>",
  "expectedRevision": null,
  "action": { "kind": "catalogue" }
}

Use these action bodies inside that envelope:

{"kind":"snapshot"}
{"kind":"get","field":"P7.participantCount"}
{"kind":"set","field":"P7.participantCount","value":1}
{"kind":"apply","edits":[{"kind":"set","field":"P7.output.csv","value":true},{"kind":"set","field":"P7.output.tsv","value":false}]}
{"kind":"validate","owner":null}

set and apply require the current revision. Atomic owner operations belong inside apply.edits, using {kind:"operation", owner, operation, arguments}. Read generated row and variant IDs from the replies; do not guess them. Validation issues can accompany an applied, incomplete draft.

Open, edit & save a new version

This workflow uses the file-command interfaces below, whose integration is still pending at the documented checkpoint.

  1. Open the existing recipe with openRecipe. Keep the original file.
  2. Select the work directory and freshly bind its media. Restored declarations do not restore permissions or media readiness.
  3. Inspect the snapshot, edit through the owning settings or list operations, and read back the normalized values.
  4. Resolve validation issues and confirm the required sections in order. P7 captures the final feedback configuration when saving.
  5. Call saveRecipe and use the actual returned basename and exact-byte receipt.

New exports use recipeId_YYYY-MM-DD_HH-mm-ss-SSSZ.json in UTC, with _001 through _999 collision suffixes. Filename time does not change canonical recipe content or its hashes.

The native writer publishes a new file without replacing an existing destination and requires a filesystem with hard-link support. Browser saving suggests the same name and rejects a nonempty selected file, but cannot guarantee atomic exclusion of concurrent writers or distinguish an existing empty file.

Results & errors

Replies identify the session, request and current revision. ok is a successful query; applied and incomplete describe an edit. Inspect issues and any effect receipt on rejected, canceled or incomplete.

Example rejected edit

This response shape was observed for a read-only media count. Session and request placeholders replace the transient receipt IDs; revision 1 belongs to that example session.

{
  "schema": "affect-research-planner-command-result",
  "version": 1,
  "sessionId": "<actual session UUID>",
  "requestId": "<matching request UUID>",
  "status": "rejected",
  "revision": 1,
  "result": null,
  "issues": [{
    "owner": "P1", "field": "P1.media.count",
    "code": "read_only",
    "message": "This setting is derived or read-only."
  }]
}

For stale revisions, read current state before preparing a new edit. For invalid values or missing dependencies, follow the returned owner, field and message. A successful edit may still need validation and confirmation.

Cancellation does not undo a file already written. Reconcile an uncertain write with the same request identity; blindly retrying with a new ID can repeat an external effect. A process timeout or nonzero exit is not proof that no work occurred.
