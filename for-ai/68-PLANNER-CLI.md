## Scope and authority

Use one typed authoring gateway backed by existing segment owners, drafts,
validators and master compiler. A CLI adapter is not a second editor, alternate
compiler, arbitrary JSON patcher or DOM automation interface. Native services
retain explicit filesystem authority, actual media inspection, strict final
validation and exact file receipts. Opening JSON does not restore permissions
or prove current media readiness.

The first CLI owns a hidden Planner process and exchanges bounded commands and
results through inherited process I/O. Set visibility before window creation;
retain the real native parent/media lifecycle for metadata inspection. Do not
foreground or control an existing researcher window. Live attachment, network
listeners, pairing and a persistent daemon are deferred. No general shell,
script execution or unrestricted filesystem bridge is added. Runner execution,
acquisition and recording remain separate.

The setting registry describes stable identifier, owner, type, units/range/enum,
authored and effective values, writability and invalidation. Distinguish authored,
derived, compatibility-only and transient state. Stable-ID list operations must
cover ordered resources as well as scalars. Preserve inactive saved alternatives.
Invalid drafts remain visible with issues, without silent defaults or fallback
to an older valid contribution.

One monotonic authored revision fences mutation, confirmation and export,
including invalid edits and edit/revert. Require explicit revision comparison,
bounded requests, duplicate handling, atomic edit batches and operation/session
shutdown fences. Native file/media operations are separate from synchronous
atomic edits. Report a completed write separately from adoption as the current
saved state; cancellation cannot undo a file that was already written.

## Timestamped recipe versions

Every new export receives a readable prefix and Windows-safe UTC creation
timestamp with subsecond precision. Exact spelling belongs to the shared helper;
an example is `great-dictator-mock--20260912T153045123Z.json`. Clock time belongs
only in the filename, never in canonical content, identity, integrity hashes or
reproduction. Editing a loaded file exports a new version, preserving the old.

Native creation must prevent replacement atomically and handle collisions,
parallel writers and clock rollback. Validate before writing, verify final bytes,
and return actual filename/path through the native CLI adapter with the receipt.
The GUI uses the same default name convention. Browser mechanisms may provide
only a timestamp suggestion or selected-handle replacement: state their actual
guarantee instead of claiming native exclusivity from an API that cannot supply
it. Never silently overwrite an earlier version.
