## Project-authored boundaries

The closed Research contract family, canonical JSON encoding, settings/plan
hash binding, participant-code derivation, browser journal protocol, native run
lifecycle, CSV/TSV projection, recovery policy, input presets, visual color
anchors, and five mappings beyond the directly retained AffectTracker defaults
are project-authored engineering decisions. Automated conformance establishes
only the specified software properties. It does not establish construct
validity, study validity, perceived-affect validity, physiological inference,
diagnosis, or research readiness.
