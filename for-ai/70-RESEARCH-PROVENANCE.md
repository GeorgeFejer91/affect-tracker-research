## Project-authored boundaries

The closed Research contract family, package and legacy-authoring readers,
canonical JSON encoding, package/settings/assets/assignment/protocol hash
binding, independent-instance reproduction gate, participant-code derivation,
browser journal protocol, native run lifecycle, CSV/TSV projection, recovery
policy, input presets, visual color anchors, and five mappings beyond the
directly retained AffectTracker defaults are project-authored engineering
decisions. Automated conformance establishes only the specified software
properties. It does not establish randomization quality, construct validity,
study validity, perceived-affect validity, physiological inference, diagnosis,
or research readiness.
